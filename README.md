# Personal Finance Data Analysis Excel

## Project Overview

This project is an **Excel-based Personal Finance Data Analysis Dashboard** created to analyze income, expenses, savings, budgeting, and financial trends using a structured financial dataset.

## Key Features

* Income and Expense Analysis
* Net Savings & Saving Rate
* Budget Utilization Analysis
* Monthly Financial Trends
* Expense Category Analysis
* Payment Method Analysis
* Savings Goal Tracking
* KPI Cards
* PivotTables & PivotCharts
* Interactive Slicers and Filters

## Tools Used

* Microsoft Excel
* Excel Formulas
* PivotTables
* PivotCharts
* Slicers
* Data Analysis & Visualization

## Key Metrics

The dashboard tracks:

* Total Income
* Total Expenses
* Net Savings
* Saving Rate
* Budget Utilization
* Balance

## Project Goal

The goal of this project was to practice **Excel data analysis, financial calculations, PivotTables, visualization, and dashboard development** by turning raw personal finance data into an interactive and easy-to-understand report.
